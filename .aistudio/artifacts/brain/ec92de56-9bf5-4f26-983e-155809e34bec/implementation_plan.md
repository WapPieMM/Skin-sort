# แผนการพัฒนาระบบตรวจจับสกินจากภาพแคปหน้าจอ (RoV 5×3 & 5×2 Badge-Resistant Skin Matcher)

## 1. ภาพรวมฟีเจอร์ (Feature Overview)
เพิ่มปุ่ม **`ตรวจจับ`** บนแถบเครื่องมือของตารางพรีวิว เพื่อให้ผู้ใช้อัปโหลดภาพแคปหน้าจอจากในเกม RoV แบบ **5 คอลัมน์ × 3 แถว (15 ใบต่อภาพ เช่น บน iPad ที่มีแถวที่ 3 โผล่มาครึ่งใบ)** หรือ **5 × 2 (10 ใบ)** แล้วให้ระบบตัดแยกการ์ดแต่ละใบไปแมตช์กับรูปสกินในคลังของเว็บ โดย **ข้ามบริเวณที่มีป้ายระดับสกิน/ป้ายคอลแลปส์และตัวหนังสือบัง** เพื่อให้จับคู่ได้อย่างแม่นยำแม้ภาพไม่เหมือนกัน 100%

## 2. การออกแบบอัลกอริทึมให้ทนต่อป้ายบังและแถวที่ถูกตัดขอบ (Core Technical Design)

### 2.1 การตรวจจับและตัดแยกการ์ด 5×3 (15 ใบ) และ 5×2 (10 ใบ)
- **ตรวจจับกรอบการ์ดอัตโนมัติ (Auto Card-Box & Grid Detector):**
  - ค้นหาตำแหน่งกรอบการ์ดทั้ง 5 คอลัมน์ และตรวจจับว่าในภาพมี **3 แถว (15 ใบ)** หรือ **2 แถว (10 ใบ)** อัตโนมัติ (พร้อมปุ่มสลับ `5×3 (15 ใบ)` / `5×2 (10 ใบ)` ได้ในคลิกเดียว)
  - **รองรับแถวที่ 3 ที่เห็นไม่เต็มใบ (Partial Row 3 Handling):** ในภาพแคปหน้าจอ 5×3 (เช่น `IMG_0442`) แถวที่ 3 ด้านล่างจะเห็นเฉพาะช่วงบน–กลางของการ์ด (ประมาณ 60–65% บนของใบ) ระบบจะคำนวณสัดส่วนความสูงจริงของการ์ดจากแถวที่ 1–2 แล้วเทียบเฉพาะส่วนที่มองเห็นของแถวที่ 3 กับตำแหน่งเดียวกันของรูปในคลัง

### 2.2 ระบบเปรียบเทียบเฉพาะ "โซนปลอดป้ายบัง" (Badge-Masked & Text-Masked Matching)
เนื่องจากรูปสกินในคลังเว็บมักมี **ป้ายโลโก้/ระดับสกินมุมขวาบน** (เช่น `Attack on Titan`, `Jujutsu Kaisen`, `Limited`) และ **ชื่อสกินด้านล่าง** (`Mikasa Ackermann`, `Satoru Gojo`) ในขณะที่รูปในเกมมี **ชื่อฮีโร่และแต้มความชำนาญด้านล่าง** (`Tulen 10000`, `Aoi 10000`):
- **Mask โซนที่มีสิ่งบดบังออกจากการคำนวณ (Zero/Low Weight Mask):**
  - **ตัดโซนมุมขวาบน (`Top-Right Badge Mask`: ช่วงบน `0%–24%`, ช่วงขวา `40%–100%`)** ออก เพื่อไม่ให้ป้ายโลโก้คอลแลปส์หรือป้ายระดับสกินมากวนค่าสี
  - **ตัดโซนแถบตัวอักษรด้านล่าง (`Bottom Caption/Mastery Mask`: ช่วงล่าง `65%–100%`)** ออก เพื่อไม่ให้ชื่อสกิน ชื่อฮีโร่ หรือแถบแต้มความชำนาญมากวนการเปรียบเทียบ (และทำให้แถวที่ 3 ที่ถูกตัดขอบล่างใช้เกณฑ์เดียวกันได้พอดี)
- **โฟกัสเปรียบเทียบเฉพาะ "โซนใบหน้าและลำตัวช่วงกลาง–ซ้ายบน" (`Core Artwork Zone: ช่วงความสูง 18%–64%`):**
  - ใช้การเลื่อนทาบหลายตำแหน่ง (Multi-Offset Alignment `±6%` ทั้งแนวตั้งและแนวนอน) เพื่อชดเชยกรณีที่รูปในคลังซูมหรือครอปเหลื่อมกับรูปในเกมเล็กน้อย
  - คำนวณความเหมือนผสมผสาน 3 ค่าในโซนปลอดป้าย:
    1. **Normalized Cross-Correlation (NCC) ของสี LAB/RGB** (ทนต่อความสว่าง/คอนทราสต์ต่างกัน)
    2. **โครงสร้างเส้นขอบและแสงเงาใบหน้า (Sobel Edge / Gradient Fingerprint)**
    3. **Robust Trimmed Patch Matching (ตัดตารางย่อย 20% ที่ค่าต่างกันมากที่สุดออกโดยอัตโนมัติ)** เผื่อกรณีที่ป้ายโลโก้บางสกินใหญ่กินพื้นที่ลงมามากกว่าปกติ

### 2.3 หน้าสรุปตรวจสอบผลลัพธ์และเปลี่ยนตัวที่คลาดเคลื่อน (Review & Confirm Modal)
- แสดงรายการการ์ดทั้ง **15 ใบ (5×3)** หรือ **10 ใบ (5×2)** เรียงตามลำดับในภาพ:
  - แสดงรูปที่ตัดจากสกรีนช็อต คู่กับ **รูปสกินในคลังที่แมตช์ได้ (อันดับ 1)** พร้อมเปอร์เซ็นต์ความมั่นใจ
  - แสดงตัวเลือกสำรอง (อันดับ 2–3) ให้กดสลับได้ทันทีในคลิกเดียว หรือกดค้นหาสกินอื่นในคลังได้หากต้องการเปลี่ยน
  - **ข้ามใบที่ไม่มีในคลังอัตโนมัติ:** หากการ์ดใบไหนในภาพยังไม่มีรูปสกินอยู่ในคลังของเว็บ ระบบจะตั้งสถานะเป็น **"ข้าม (ไม่มีในคลัง)"** ให้อัตโนมัติ ไม่นำเข้ามั่ว
- ปุ่มยืนยัน **`+ นำเข้าสกินที่แมตช์เข้าตารางพรีวิว`** เพื่อส่งสกินที่แมตช์ได้ทั้งหมดเข้าสู่ตารางพรีวิวทันที

## 3. รายการไฟล์ที่จะสร้างและอัปเดต (Files to Create / Update)
1. **`/src/utils/skinScanner.js` (สร้างใหม่):**
   - ระบบตัดการ์ด `5×3 (15 ใบ)` และ `5×2 (10 ใบ)` พร้อมรองรับแถวที่ 3 ที่เห็นครึ่งใบ และอัลกอริทึม `Badge-Masked Core Artwork Matcher` (NCC + Edge Gradient + Outlier Patch Trimming)
2. **`/src/components/SkinScannerModal.jsx` (สร้างใหม่):**
   - หน้าต่าง Modal สำหรับอัปโหลดภาพแคปหน้าจอ (รองรับหลายภาพพร้อมกัน), สลับโหมด `5×3` / `5×2`, แสดงผลลัพธ์จับคู่แต่ละใบ, สลับตัวเลือกสำรอง และกดนำเข้าตารางพรีวิว
3. **`/src/App.jsx` & `/src/style.css` (อัปเดต):**
   - เพิ่มปุ่ม **`ตรวจจับ`** บนแถบเครื่องมือของตารางในหน้า 2 และหน้า 3/4 เพื่อเปิดใช้งาน `SkinScannerModal`
